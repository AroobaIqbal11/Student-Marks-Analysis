# Student Marks Analysis | Microsoft Excel

## 📌 Project Overview
This is a beginner-level Data Analytics project created using Microsoft Excel to analyze student academic performance.

## 🎯 Project Objectives
- Calculate total marks of students.
- Calculate student percentages.
- Identify PASS and FAIL results.
- Assign grades based on percentages.
- Calculate average marks.
- Organize and analyze student records.

## 📊 Dataset Information
The dataset contains:
- Student Names
- English Marks
- Mathematics Marks
- Computer Marks
- Total Marks
- Percentage
- Result (PASS/FAIL)
- Grades

## 🛠️ Excel Skills & Functions Used
- SUM() – Calculate total marks.
- IF() – Determine PASS/FAIL results and assign grades.
- AVERAGE() – Calculate average marks.
- Conditional Formatting – Highlight PASS and FAIL results.
- Sorting – Arrange student records in ascending and descending order.
- Filtering – Display specific student records.
- Basic Data Formatting – Organize and format the worksheet.

## 💻 Tools Used
- Microsoft Excel

## 📚 Learning Outcomes
- Practiced basic Excel formulas.
- Learned to organize student data.
- Applied sorting and filtering.
- Used conditional formatting to highlight results.
- Analyzed student academic performance.
